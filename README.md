# Amal Thomas — Space AI Portfolio

## Open in VS Code
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` with Live Server, or double-click it.

## Add your profile photo
Put your profile photo at:
`images/profile.jpg`

The hero automatically shows "AT" until that file is added.

## Add the other achievement photos
The carousel already contains:
- `images/2023-nasa-space-apps.jpg` — included from the uploaded 2023 trophy photo.
- `images/2024-nasa-space-apps.jpg`
- `images/2025-nasa-space-apps.jpg`

Add your 2024 and 2025 images using those exact filenames.

## Features
- Blue cinematic space theme
- Compact rotating NASA Space Apps achievement carousel
- Automatic slide rotation + arrows + dots
- Interactive orbit that responds to mouse movement
- Clickable orbit points
- Responsive mobile layout
